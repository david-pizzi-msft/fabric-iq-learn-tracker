# Enable continuous planning with rolling forecasts

Summarize this article for me

Rolling forecasts continuously extend the forecast horizon. When actual data is available for a forecasted period, the forecast is closed, and the report displays the actuals.

In this section, you learn how to close forecasts and extend forecast periods.

## Close forecasts

Forecasts should be closed as actuals become available. Once a forecast is closed, it can no longer be edited.

Tip

To hide closed forecasts, deselect **Period** > **Show Closed Periods**.

1. Go to **Model** > **Period**. Select **Close Period**.
2. If multiple forecasts exist, select the forecast to close.
3. Select the forecast period to closeâcurrent or previous year, quarter, or month. A custom period can also be specified.

   [![Screenshot of closing forecasts.](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/close-forecast-period.png)](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/close-forecast-period.png#lightbox)
4. Select **Preview**. The open and closed periods are displayed. Select **Save**.

   [![Screenshot of forecast period preview.](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/preview-open-closed-periods.png)](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/preview-open-closed-periods.png#lightbox)

   The forecast is closed for January and can't be edited.

   [![Screenshot of closed period.](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/period-closed-example.png)](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/period-closed-example.png#lightbox)

## Extend forecast periods

As forecast periods are closed, new future periods are added to maintain a rolling forecast.

1. Go to **Model** > **Period**. Select **Close Period**.
2. Select the period to close.
3. Select **Extend Forecast Range** and set the duration.

   [![Screenshot of the option to extend forecasts.](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/extend-forecast-option.png)](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/extend-forecast-option.png#lightbox)
4. Review the closed and open periods. Select **Save**.

   ![Screenshot of open and closed forecasts.](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/review-forecast-periods.png)

   As the open forecast for April 2026 is closed, a rolling forecast is created by simultaneously extending the forecast into 2027.

   [![Screenshot of rolling forecasts.](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/rolling-forecast.png)](../media/planning-forecasting/planning-how-to-manage-rolling-forecasts/rolling-forecast.png#lightbox)
