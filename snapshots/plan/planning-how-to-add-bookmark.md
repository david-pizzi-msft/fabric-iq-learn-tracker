# Save analysis and insights with bookmarks

Summarize this article for me

Bookmarks help you capture the current state of your report, such as applied filters, rankings, layout adjustments, and formatting. Use bookmarks to return to key insights with a single click or share tailored views with specific stakeholders.

## Prerequisite

- You have access to the plan item.

## Save applied filters

Instead of manually reapplying filters and toggling columns for every review, use bookmarks to preserve curated views of your data. Easily switch between broad overviews and granular slices filtered by product, region, or specific KPIs.

1. Select the **Bookmark** icon to open the **Bookmark** pane.

   [![Screenshot of the bookmark icon and the bookmark side pane.](media/planning-how-to-add-bookmark/add-bookmark-icon.png)](media/planning-how-to-add-bookmark/add-bookmark-icon.png#lightbox)
2. Create a bookmark under the appropriate tab based on your sharing needs:

   - **Public**: Visible to users with access to the sheet, subject to [role-based bookmark permissions](planning-how-to-manage-security).
   - **Private**: Accessible only to you (the creator).

   Select **Add New**.

   [![Screenshot of creating a new bookmark in a planning sheet.](media/planning-how-to-add-bookmark/create-new-bookmark.png)](media/planning-how-to-add-bookmark/create-new-bookmark.png#lightbox)
3. Select the **More options (â¦)** menu to rename the bookmark.
4. In the **Planning** ribbon, go to **Filter** > **Add New Filter**.
5. Enter a name to identify the filter and enter the filter condition. In this example, the filter displays the rows with total quantity greater than 1k. Select **Save** to apply the filter.

   [![Screenshot of creating a filter condition to display rows with quantity greater than 1k.](media/planning-how-to-add-bookmark/create-filter-condition.png)](media/planning-how-to-add-bookmark/create-filter-condition.png#lightbox)
6. In the **Planning** ribbon, go to **Show Columns** and select only the dimensions and measures required for your current analysis.

   [![Screenshot of using the Show Columns option to hide the sales and profit measures.](media/planning-how-to-add-bookmark/select-dimensions-measures-display.png)](media/planning-how-to-add-bookmark/select-dimensions-measures-display.png#lightbox)
7. Go to the **More options (â¦)** menu and select **Update** to save the changes to the bookmark.

   [![Screenshot of the update bookmark option in the more options menu.](media/planning-how-to-add-bookmark/update-bookmark-option.png)](media/planning-how-to-add-bookmark/update-bookmark-option.png#lightbox)
8. Switch between focused data slices, such as isolating a particular product line, focusing on a specific region, or hiding non-essential measures and dimensions by using bookmarks.

   [![Animation showing how to switch views between different bookmarks.](media/planning-how-to-add-bookmark/switch-bookmarks-filters.gif)](media/planning-how-to-add-bookmark/switch-bookmarks-filters.gif#lightbox)

## Capture top and bottom performers

Instead of scanning through hundreds of rows to spot outliers, use ranking rules to isolate your top revenue drivers or underperforming accounts. Save these ranked configurations as bookmarks to preserve specific threshold views and switch effortlessly between global overviews and targeted performance lists.

1. Create a new bookmark.
2. In the **Planning** ribbon, select **Top n**.
3. Configure the rule to display the top or bottom-performing categories. In this example, you show the top two product subcategories with the highest sales in Q1. Select **Apply** to rank your data.

   [![Screenshot of configuring ranking to display the top two subcategories.](media/planning-how-to-add-bookmark/configure-ranking-sub-category.png)](media/planning-how-to-add-bookmark/configure-ranking-sub-category.png#lightbox)
4. Go to the **More options (â¦)** menu to rename the bookmark. Select **Update** to save your changes.

   [![Screenshot of option to update the top performing category bookmark.](media/planning-how-to-add-bookmark/bookmark-update-option-top-categories.png)](media/planning-how-to-add-bookmark/bookmark-update-option-top-categories.png#lightbox)
5. Once configured, capture these ranked views as bookmarks so report consumers can immediately benchmark top performers against underperforming segments.

   [![Screenshot of configuring ranking to display the bottom performing categories and creating a bookmark.](media/planning-how-to-add-bookmark/bottom-performing-sub-categories.png)](media/planning-how-to-add-bookmark/bottom-performing-sub-categories.png#lightbox)

## Highlight key metrics with formatting

Use bookmarks to capture custom formatting and layout changes so critical variances and KPI thresholds stand out immediately. Saving these visual states allows you to switch seamlessly between standard grid views and executive-ready highlights without having to reconfigure your planning sheet.

1. Create a new bookmark.
2. Select the cells to highlight. In the **Format** ribbon, select the background and font color to apply.
3. Select **Update** from the **More options (...)** menu to save formatting.

   [![Screenshot of applying formatting and updating the bookmark.](media/planning-how-to-add-bookmark/apply-formatting-cells.png)](media/planning-how-to-add-bookmark/apply-formatting-cells.png#lightbox)
4. In the **Planning** ribbon, select **Layout** and choose your preferred report structure (such as Hierarchy, Outline, Stepped, Table, or Tree). Select **Update** from the **More options (â¦)** menu next to the bookmark to save the layout changes.

   [![Screenshot of option to change the planning sheet layout.](media/planning-how-to-add-bookmark/change-sheet-layout.png)](media/planning-how-to-add-bookmark/change-sheet-layout.png#lightbox)
5. Apply advanced number customizations from **Appearance** settings and save the changes using bookmarks. To apply semantic formatting, you need a Planner session and workspace permissions that allow you to edit the plan item. See [Planning roles](overview-roles).

   [![Screenshot of appearance settings to enable semantic number formatting in the planning sheet.](media/planning-how-to-add-bookmark/appearance-settings.png)](media/planning-how-to-add-bookmark/appearance-settings.png#lightbox)
6. Customize report layouts, cell formatting, appearance settings, totals, and number formats, then save the entire configuration as a bookmark for instant reuse.

   [![Animation showing how to create bookmarks with different layouts and formatting.](media/planning-how-to-add-bookmark/switch-layout-formatting-bookmarks.gif)](media/planning-how-to-add-bookmark/switch-layout-formatting-bookmarks.gif#lightbox)

## Manage bookmark options

Select **More options (â¦)** next to a bookmark to access the following actions:

- **Update**: Overwrite the bookmark with your current report view and settings.
- **Make default**: Set the bookmark as the default view whenever the sheet is opened.
- **Promote to Public**: Move a private bookmark to the **Public** tab so other users can access it.
- **Rename**: Edit the bookmark's display name.
- **Delete**: Permanently remove the bookmark.
- **Copy link**: Copy a direct, shareable URL to the bookmark.
- **Group**: Organize related bookmarks into a separate section.
