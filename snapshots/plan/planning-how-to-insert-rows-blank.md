# Insert blank rows

Summarize this article for me

In reports and financial statements, you might need to add blank rows to improve readability and formatting. In planning, you can insert blank rows in table or matrix reports to create visual spacing for better readability and presentation.

This article explains how to insert and remove blank rows.

## Insert a blank row

1. Select the row underneath the space where you want to insert the blank row. The blank row will be inserted above the selected row.
2. Hover over the row and select the row gripper.
3. Select **Insert** > **Add Empty Row**.

   ![Screenshot of steps to insert a blank row.](media/planning-how-to-insert-rows-blank/insert-blank-row.png)

A blank row is inserted above the selected row. You can insert blank rows at any level of the hierarchy.

## Delete a blank row

1. Hover over the blank row and select the row gripper.
2. Select **Remove Empty Row**.

   ![Screenshot of steps to remove a blank row.](media/planning-how-to-insert-rows-blank/delete-blank-row.png)
