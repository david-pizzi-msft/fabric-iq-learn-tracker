# Build financial reports with intelligence sheets

Summarize this article for me

Intelligence sheets include built-in features that can present financial data in a clear format. You can organize metrics into a structured layout that supports both on-screen analysis and formatted exports.

You can apply custom number formatting and scaling, apply single-click templates, display totals and subtotals, and insert calculations. Together, these capabilities help you create presentation-ready financial reports that support planning, analysis, and decision-making.

This article provides a basic overview of how to create financial reports with intelligence sheets.

## Format numeric data

1. Select **Number** > **Decimal icons** to increase or decrease the number of decimal places displayed. This setting applies to all measures in the report.
2. To adjust decimal places for a specific measure, select the measure and use the increase or decrease decimal buttons.

   [![Screenshot of the decimal place button that added a decimal place to every value in the column.](media/intelligence-how-to-build-financial-reports/decimal-places.png)](media/intelligence-how-to-build-financial-reports/decimal-places.png#lightbox)
3. Select the **Prefix/Suffix** button, then enter the desired prefix or suffix.

   [![Screenshot of the prefix/suffix button adding a prefix or suffix to every value in the column.](media/intelligence-how-to-build-financial-reports/prefix-suffix.png)](media/intelligence-how-to-build-financial-reports/prefix-suffix.png#lightbox)
4. Enable **Semantic Formatting** from **Number Settings** to highlight positive/negative values.

   [![Screenshot of the semantic formatting button in the Appearance pane.](media/intelligence-how-to-build-financial-reports/semantic-formatting.png)](media/intelligence-how-to-build-financial-reports/semantic-formatting.png#lightbox)

## Set number scaling

1. Select the **Quick Format** option to set scaling at the report level. This setting applies to all measures.

   [![Screenshot of the Quick Format button in the Number section of the menu ribbon.](media/intelligence-how-to-build-financial-reports/quick-format.png)](media/intelligence-how-to-build-financial-reports/quick-format.png#lightbox)
2. For measures with mixed granularities, select the measure to set the scaling factor.

   [![Screenshot of the Quick Format options selecting between scaling factors such as Auto, Thousands, and Millions.](media/intelligence-how-to-build-financial-reports/quick-format-measure.png)](media/intelligence-how-to-build-financial-reports/quick-format-measure.png#lightbox)

## Apply and customize built-in templates

Built-in report templates provide a quick starting point for creating reports. They reduce the time and effort required to build reports from scratch.

Tip

Use built-in templates to save time and ensure consistency across reports.

1. Select the template you want to apply to the report.

   [![Screenshot of the Templates button in the Actions section of the menu ribbon.](media/intelligence-how-to-build-financial-reports/templates.png)](media/intelligence-how-to-build-financial-reports/templates.png#lightbox)
2. You can customize templates by formatting the header and footer and adding outlines.

   [![Screenshot of the Header & Footer tab in the menu ribbon.](media/intelligence-how-to-build-financial-reports/header-footer.png)](media/intelligence-how-to-build-financial-reports/header-footer.png#lightbox)
3. Enable grid lines from **Display Settings** to clearly demarcate various categories.

   [![Screenshot of adding grid lines to the report.](media/intelligence-how-to-build-financial-reports/grid-lines.png)](media/intelligence-how-to-build-financial-reports/grid-lines.png#lightbox)
4. Turn on **Semantic Formatting** to draw attention to values like negative variances or profits.

   [![Screenshot of the semantic formatting options being reflected in the data.](media/intelligence-how-to-build-financial-reports/semantic-formatting-2.png)](media/intelligence-how-to-build-financial-reports/semantic-formatting-2.png#lightbox)
5. Enable the **Sign in Headers** option to display the overall performance of a row category. When all the values in a particular row are negative, the row is prefixed with a minus sign.

   [![Screenshot of the Value Display options, including Sign In Headers.](media/intelligence-how-to-build-financial-reports/value-display.png)](media/intelligence-how-to-build-financial-reports/value-display.png#lightbox)
6. Customize the position of row and column subtotals when the report contains hierarchical data.

   [![Screenshot of customizing the subtotal position with the Totals button.](media/intelligence-how-to-build-financial-reports/customize-position.png)](media/intelligence-how-to-build-financial-reports/customize-position.png#lightbox)

## Insert calculated columns

1. Select **Insert Formula**.
2. Enter the calculation in the **Formula** window.
3. Press **Ctrl + Space** to open suggestions while writing a formula. This action helps you quickly discover available fields, functions, and syntax. Use the **References** tab to use dimensions and measures in your formula.

   [![Screenshot of the References tab in the Formula options in the Formula Measure pane.](media/intelligence-how-to-build-financial-reports/references.png)](media/intelligence-how-to-build-financial-reports/references.png#lightbox)

## Insert data input columns

1. Go to **Insert > Data Input**.
2. Select the data input type like checkboxes, dropdowns, and text.

   [![Screenshot of the Columns option in the Insert tab of the menu ribbon.](media/intelligence-how-to-build-financial-reports/columns.png)](media/intelligence-how-to-build-financial-reports/columns.png#lightbox)

## Export reports

Select the export icon to create fully formatted Excel and PDF exports for distribution.

[![Screenshot of the export options for the report.](media/intelligence-how-to-build-financial-reports/export.png)](media/intelligence-how-to-build-financial-reports/export.png#lightbox)
