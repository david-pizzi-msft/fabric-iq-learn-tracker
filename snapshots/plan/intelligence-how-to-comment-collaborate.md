# Collaborate with comments in intelligence sheet

Summarize this article for me

Comments are collaborative threads that facilitate conversations directly from within your report. The intelligence sheet provides a context-aware commenting solution with support for cell, row, and column-level threaded conversations. Key features include `@mentions`, email notifications, and task assignments.

## Add comments

1. Select a cell, row, or column. Select **Comment** > **Add New Comment**.
2. Use the rich text editor to format text and add hyperlinks in comments.

   [![Screenshot of a formatted comment with bold, red text.](media/intelligence-how-to-comment-collaborate/add-comment.png)](media/intelligence-how-to-comment-collaborate/add-comment.png#lightbox)
3. After adding a comment, hover over the indicator to view it.
4. You can mark important comments with a star to easily find and reference them later.

   [![Screenshot of a starred comment.](media/intelligence-how-to-comment-collaborate/star-comment.png)](media/intelligence-how-to-comment-collaborate/star-comment.png#lightbox)
5. When writeback is performed, comments added to a report are captured and saved to the destination.

   [![Screenshot of comment writeback.](media/intelligence-how-to-comment-collaborate/write-back-comment.png)](media/intelligence-how-to-comment-collaborate/write-back-comment.png#lightbox)

## Assign comments and tag users

1. Select **Assign to user** to search for and assign the comment to another user.

   ![Screenshot of assigning a comment to a user.](media/intelligence-how-to-comment-collaborate/assign-user.png)
2. Reply to a comment to start a thread.
3. Tag other users with `@mentions`. The `@user` mention in a comment automatically sends an email notification to that user, with a link to the report.

   ![Screenshot of a comment containing a tag to a user.](media/intelligence-how-to-comment-collaborate/tag.png)

## Resolve threads and lock comments

Resolve comment threads to indicate that an issue has been addressed. You can also lock threads and make them read-only.

- After a task is assigned, the assignee can respond in the comment thread. If the response resolves the issue, you can close the thread. Select **Resolve Thread**.

  [![Screenshot of resolving a comment.](media/intelligence-how-to-comment-collaborate/resolve-thread.jpg)](media/intelligence-how-to-comment-collaborate/resolve-thread.jpg#lightbox)
- Select the undo icon or reply to a thread to reopen it.

  [![Screenshot of reopening a thread.](media/intelligence-how-to-comment-collaborate/reopen-thread.png)](media/intelligence-how-to-comment-collaborate/reopen-thread.png#lightbox)
- Lock comments to prevent further editing and replies. Select **Lock Thread**.

  [![Screenshot of locking a thread.](media/intelligence-how-to-comment-collaborate/lock-thread.png)](media/intelligence-how-to-comment-collaborate/lock-thread.png#lightbox)
- Select the unlock icon to make the thread editable again.

  [![Screenshot of unlocking a thread.](media/intelligence-how-to-comment-collaborate/unlock-thread.png)](media/intelligence-how-to-comment-collaborate/unlock-thread.png#lightbox)

## Manage comments in a report

Work with threads by viewing, replying, sorting, and filtering discussions in the comments pane. You can also star, assign, lock, and resolve threads.

- Select **Comments** > **View All Comments** to browse all the comments from a single view. In the detailed view, you can see all comments and replies with their timestamps, along with the specific row and column dimensions to which each comment is linked. You can also reply to comments in the detailed view.

  You can keep the comments panel visible at all times by enabling **Show comments panel** in **Comments > Settings**.

  [![Screenshot of comments panel.](media/intelligence-how-to-comment-collaborate/view-all-comments.jpg)](media/intelligence-how-to-comment-collaborate/view-all-comments.jpg#lightbox)
- Use the **Simple** view to see a concise summary of all the comments.

  [![Screenshot of summary view.](media/intelligence-how-to-comment-collaborate/simple-view.png)](media/intelligence-how-to-comment-collaborate/simple-view.png#lightbox)
- Sort based on creation time and filter comments by type, assignee, or creation date for quicker access.

  [![Screenshot of sorting and filtering in the comments panel.](media/intelligence-how-to-comment-collaborate/sort-filter-comments.png)](media/intelligence-how-to-comment-collaborate/sort-filter-comments.png#lightbox)
- Select the refresh icon to update the report with the latest comments.

  [![Screenshot of comments refresh.](media/intelligence-how-to-comment-collaborate/refresh-comment.png)](media/intelligence-how-to-comment-collaborate/refresh-comment.png#lightbox)
