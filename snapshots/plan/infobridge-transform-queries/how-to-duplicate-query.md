# Duplicate a query in Infobridge

Summarize this article for me

You can duplicate an existing query to create a copy that you can modify independently of the original query.

## Duplicate a query

In the **Queries** pane, select the query you want to duplicate. On the **Home** tab, select **Duplicate Query**.

[![Screenshot of the Home tab with Duplicate Query highlighted and the Queries pane showing the available queries in Infobridge.](../media/infobridge-transform-queries/how-to-duplicate-query/queries-on-infobridge.png)](../media/infobridge-transform-queries/how-to-duplicate-query/queries-on-infobridge.png#lightbox)

## Work with the duplicated query

After you select **Duplicate Query**, a copy of the selected query is added to the **Queries** pane.

[![Screenshot of the Queries pane showing the duplicated query.](../media/infobridge-transform-queries/how-to-duplicate-query/after-pressing-duplicate-query.png)](../media/infobridge-transform-queries/how-to-duplicate-query/after-pressing-duplicate-query.png#lightbox)

The duplicated query is created as a separate query that you can transform without changing the original query.
