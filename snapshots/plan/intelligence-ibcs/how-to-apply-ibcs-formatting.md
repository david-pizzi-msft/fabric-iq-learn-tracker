# Apply IBCS formats

Summarize this article for me

The intelligence sheet is International Business Communication Standards (IBCS) certified, so you can create standardized business reports on top of your semantic models without manually formatting visual elements.

The visualization library includes a set of IBCS-compliant charts designed for business reporting. These charts present performance metrics using consistent layouts, colors, and notation. You can also apply IBCS table templates to present actual values and variances in a consistent, readable format.

Tip

Intelligence sheets support both strict and flexible IBCS standards. Use the **Minimal** theme to customize the prebuilt IBCS themes to meet organization-specific requirements.

In this article, you learn how to configure charts and tables by using the different types of built-in IBCS templates.

## Enable IBCS charts

To use IBCS-compliant charts in the dashboard, select **IBCS** in the **Visualizations** pane. This selection filters the visualization library to display only IBCS charts.

[![Screenshot of selecting the IBCS button in the visualizations pane to filter only IBCS charts.](../media/intelligence-ibcs/how-to-apply-ibcs-formatting/ibcs-button-visualizations-pane.png)](../media/intelligence-ibcs/how-to-apply-ibcs-formatting/ibcs-button-visualizations-pane.png#lightbox)

Alternatively, after creating the dashboard, go to **Canvas** > **Themes** in the **Intelligence** ribbon, and select **IBCS** to apply an IBCS theme.

[![Screenshot of applying the built-in IBCS theme to a dashboard from canvas settings.](../media/intelligence-ibcs/how-to-apply-ibcs-formatting/ibcs-dashboard-theme.png)](../media/intelligence-ibcs/how-to-apply-ibcs-formatting/ibcs-dashboard-theme.png#lightbox)

Important

Map comparison measures to the appropriate data wells to apply the correct IBCS formatting. Assign previous year values to **Comparison 1**, planned or target values to **Comparison 2**, and forecast values to **Comparison 3**.
