# Create conditional formatting rules

Summarize this article for me

Conditional formatting helps you highlight important data points in a planning sheet by applying visual cues such as colors, icons, and styles based on defined rules. This formatting improves readability and directs attention to key performance indicators in high-density tabular reports.

## Prerequisite

- You have access to the Planning sheet with the required dataset.

## Create a conditional formatting rule

1. In the Planning sheet navigate to **Format >** **Conditional formatting**.
2. Select **Create rule**.

   [![Screenshot of creating rules in conditional formatting.](../media/planning-conditional-formatting/how-to-create-rules/create-rule.png)](../media/planning-conditional-formatting/how-to-create-rules/create-rule.png#lightbox)
3. Enter a **Title** for the rule.
4. Select where to apply formatting using **Apply to** (rows, columns, headers, or measures).

   [![Screenshot of configuring rules in conditional formatting.](../media/planning-conditional-formatting/how-to-create-rules/configure-rules.png)](../media/planning-conditional-formatting/how-to-create-rules/configure-rules.png#lightbox)
5. Select the formatting scope using **Row hierarchy levels**:

   - Values only
   - Totals only
   - Values and totals

   ![Screenshot of row hierarchy while configuring rules in conditional formatting.](../media/planning-conditional-formatting/how-to-create-rules/row-hierarchy.png)
6. Select a rule type from **Format by**:

   - Rules (IF conditions): For more information about configuring rules using IF conditions, see [Configure rules using IF conditions](how-to-format-if).
   - Color scale: For more information about configuring rules using color scale, see [Configure rules using format by color scale](how-to-format-color-scales).
   - Classification: For more information about configuring rules classification, see [Configure rules using format by classification](how-to-format-classification).

   ![Screenshot of format by while configuring rules in conditional formatting.](../media/planning-conditional-formatting/how-to-create-rules/format-by.png)
7. Select **Apply** to create the rule.

   [![Screenshot of created rule in conditional formatting.](../media/planning-conditional-formatting/how-to-create-rules/rule-created.png)](../media/planning-conditional-formatting/how-to-create-rules/rule-created.png#lightbox)
