# Add notes in a planning sheet

Summarize this article for me

You might find the notes feature of your planning sheets to be useful for contextual explanation and documentation. For example, with notes you can help interpret data, justify values, and improve decision-making. Planning enables data-level annotation, meaning that you can document insights at granular levels such as rows, columns, or individual cells.

## Prerequisite

Before you can add notes, ensure that you have access to a planning sheet.

## Add a note to a cell

1. Select the cell to add a note in your planning sheet.
2. Go to **Planning** > **Notes** > **Add New Note**.

   [![Screenshot of adding notes.](media/planning-how-to-add-notes/add-note.png)](media/planning-how-to-add-notes/add-note.png#lightbox)
3. Enter your note, apply formats, and select **Save**.

   ![Screenshot of formatting notes.](media/planning-how-to-add-notes/format-notes.png)

The note is now associated with the selected data point.

Tip

You can select multiple cells and add a single note that applies to all of them.
[![Screenshot of adding a note to multiple cells.](media/planning-how-to-add-notes/sheet-notes.png)](media/planning-how-to-add-notes/sheet-notes.png#lightbox)

Hover over the note indicator to see the note.

![Screenshot of hovering over a note indicator.](media/planning-how-to-add-notes/hover-over-notes.png)

To edit an existing note, select the **Pencil** icon on the note box. To delete an existing note, select the **Delete** icon on the note box.

### Add notes at the row or column level

1. Select the row or column header, and then select **Notes** > **Add New Note**.
2. Enter a note in the corresponding notes field, and then select **Save**.

   [![Screenshot of adding notes at the column level.](media/planning-how-to-add-notes/column-notes.png)](media/planning-how-to-add-notes/column-notes.png#lightbox)

The note applies to the entire row or column, and it's visible across related data.

[![Screenshot of adding notes at the row level.](media/planning-how-to-add-notes/row-notes.png)](media/planning-how-to-add-notes/row-notes.png#lightbox)

## Add report-level notes

1. Go to **Planning** > **Notes** > **Report Summary**.

   ![Screenshot of showing notes at report level.](media/planning-how-to-add-notes/report-level-notes.png)
2. Use the text editor to enter your note.
3. Apply formatting that you want, such as bullet points, bold or italic text, and hyperlinks.
4. Select **Save**.

This note provides a high-level summary for the report.

[![Screenshot of showing a report summary.](media/planning-how-to-add-notes/report-summary.png)](media/planning-how-to-add-notes/report-summary.png#lightbox)

## Add footnotes

Footnotes display notes collectively at the bottom of the report for easy reference.

1. Add notes to cells, rows, or columns.
2. Open the **Notes** menu.
3. Turn on the **Footnote** option.

   ![Screenshot of adding footnotes.](media/planning-how-to-add-notes/footnotes.png)

You see all notes displayed as numbered references in the footnote section.

[![Screenshot showing footnotes.](media/planning-how-to-add-notes/footnote-section.png)](media/planning-how-to-add-notes/footnote-section.png#lightbox)

## Use the notes column

The notes column provides a structured way to enter notes for each row by providing a dedicated column to capture row-level annotations.

1. On the **Notes** menu, turn on **Notes Column**.
2. Enter notes directly for each row.

   [![Screenshot showing a dedicated notes column.](media/planning-how-to-add-notes/notes-column.png)](media/planning-how-to-add-notes/notes-column.png#lightbox)

## Hide notes

You can hide notes to simplify the report view.

From the **Notes** menu, turn on **Hide All Notes**.

All notes are hidden from view, and you can't create notes while this option is active.

[![Screenshot of hiding notes.](media/planning-how-to-add-notes/hide-notes.png)](media/planning-how-to-add-notes/hide-notes.png#lightbox)

## View all notes

A consolidated panel or view displays all notes associated with the report.

1. Go to the **Notes** menu.
2. Select **View all notes**. You see a list of the notes.

   [![Screenshot of viewing all notes.](media/planning-how-to-add-notes/view-notes.jpg)](media/planning-how-to-add-notes/view-notes.jpg#lightbox)

## Configure note settings

Use note settings to customize how notes appear and behave.

1. Select **Notes** > **Settings**.
2. Configure options such as:

   - Indicator display (style and size)
   - Indicator position within the cell
   - Rollup indicator
   - Footnote border
   - Footnote height
   - Marker setting
3. Select **Apply**.

[![Screenshot of note settings.](media/planning-how-to-add-notes/note-settings.png)](media/planning-how-to-add-notes/note-settings.png#lightbox)

You can adjust how note indicators are displayed and positioned within cells.

## Use marker mode

You can use marker mode to highlight specific data points for emphasis. Marker mode lets you visually mark data for quick identification.

1. Go to **Notes** > **Marker Mode**.
2. Mark the cells, rows, or columns by using the marker icon.
3. Use **Clear Marker** to remove markings if needed.
4. In **Notes settings**, customize the color, shape, and width of markings as desired.

   [![Screenshot of marker mode in notes.](media/planning-how-to-add-notes/marker-mode.png)](media/planning-how-to-add-notes/marker-mode.png#lightbox)
